# Bio-Inspired Human Activity Recognition System

A machine learning-based system designed to recognize human activities using smartphone motion sensors, including accelerometers and gyroscopes. The project explores sensor-based activity classification and fall detection, combining data preprocessing, feature analysis, and supervised learning to identify human movement patterns.

## Overview

Human Activity Recognition (HAR) is an important application of machine learning in healthcare, wearable technology, and intelligent monitoring systems. This project uses motion sensor data to classify human activities and identify potential falls, demonstrating how machine learning can interpret movement patterns for practical applications.

## Key Features

- **Human Activity Classification:** Recognizes four activity categories: Walking, Sitting, Standing, and Falling.
- **Sensor-Based Analysis:** Uses accelerometer and gyroscope measurements to analyze movement patterns.
- **Machine Learning:** Implements a Random Forest classifier for activity recognition.
- **Fall Detection:** Explores the use of motion analysis to identify potential falls, with applications in elderly care and safety monitoring.
- **Model Evaluation:** Reports an approximate classification accuracy of 89%.

## Technology Stack

- **Programming Language:** Python
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** Scikit-learn
- **Classification Algorithm:** Random Forest
- **Dataset:** UCI Human Activity Recognition (HAR)

## How It Works

1. **Data Collection:** Uses human motion data recorded through smartphone sensors.
2. **Data Preprocessing:** Organizes and prepares sensor measurements for model training and evaluation.
3. **Model Training:** Trains a Random Forest classifier to recognize patterns associated with different activities.
4. **Activity Prediction:** Predicts the activity category based on input sensor features.
5. **Performance Evaluation:** Evaluates the model using classification accuracy and other relevant performance metrics.
